Urna Eletrônica Escolar

Sistema de identificação e controle de votação

Projeto educacional de banco de dados utilizando a plataforma Supabase.

1. Situação do Projeto

Frontend desenvolvido e publicado como demonstração.

O frontend da Urna Eletrônica Escolar já foi desenvolvido e publicado como demonstração.

Nesta etapa, será criado do zero o projeto de banco de dados utilizando o Supabase.

2. Objetivo

Estruturar uma tabela para registrar a identificação do estudante e o status de participação na votação.

Privacidade da votação:

O banco de dados não deverá relacionar o estudante à opção escolhida durante a votação.

3. Dados Previstos

A tabela do banco de dados deverá armazenar as seguintes informações:

Campo Tipo Descrição
nome_completo TEXT Nome completo do estudante.
numero_identificacao TEXT Número de identificação.
ano_letivo INTEGER Ano letivo.
serie TEXT Série escolar.
turma TEXT Turma do estudante.
ja_votou BOOLEAN Indicador de participação.

4. Controle de Participação

O campo ja_votou será utilizado para indicar se o estudante já participou da votação.

Existem dois estados possíveis:

FALSE — Não votou

TRUE — Já votou

5. Banco de Dados Supabase

O Supabase será utilizado como plataforma para criar e administrar o banco de dados da Urna Eletrônica Escolar.

  • Armazenar a identificação dos estudantes.
  • Registrar o ano letivo, série e turma.
  • Controlar se o estudante já votou.
  • Organizar as informações dos eleitores.

6. Informação Importante

Desenvolvedor: o aluno responsável pelo projeto deverá criar uma conta no Supabase.

Estudantes eleitores: não precisam criar contas individuais no Supabase para votar.

7. Conclusão

A criação do banco de dados permitirá organizar a identificação dos estudantes e controlar a participação na votação escolar.

A identificação do estudante será mantida separada da opção escolhida, respeitando a proposta de privacidade do projeto.
